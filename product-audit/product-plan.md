# 课程功能实施与验收计划

更新日期：2026-07-15

## 已确认范围

- 上课：仅 AI陪练、签到。
- 通知：列表优先，按需发布，支持状态分区和学生已读统计。
- 作业/考试：列表优先，新建与时间调整按需弹出。
- 首页侧栏：云盘下增加“生图”外链。
- 暂不建设：投票、抢答、分组研讨、实践任务。

## 功能验收

### 上课

- 教师和学生都只看到 AI陪练、签到两个卡片。
- 学生不显示“AI生成课堂练习”等教师操作。
- 页面不存在课堂积分或四类暂缓活动的入口、API、模型和迁移。

### 签到

- 默认先展示签到统计和历史记录，点击“发起签到”后才出现创建表单。
- 创建成功后立即展示二维码、短码和完整学生名单。
- 结束后二维码立即消失并切换为可重新开启状态。
- 补签、请假、缺勤操作成功后名单和统计即时更新。

### 通知

- 默认展示当前已发布通知，发布表单默认隐藏。
- 点击右上角“发布通知”打开编辑器，发布成功后立即回到已发布列表并看到新通知。
- 教师可查看已发布、定时、草稿、已撤回；学生只看到已生效通知。
- 学生展开未读通知后写入已读记录，教师端统计只计算选课学生。

### 作业和考试

- 默认展示列表，新建表单只在点击按钮后出现。
- 调整整体时间和单人延期使用站内弹窗，不使用浏览器原生 prompt。

### 生图外链

- 桌面首页侧栏中位于云盘正下方。
- 链接为 `https://zovii.studio/`，新窗口打开并包含 `noopener noreferrer`。
- 移动端首页导航保留同一入口。

## 交付门槛

- `npm run verify` 通过。
- Prisma schema 与迁移状态一致，`npm run db:seed` 无运行时错误。
- 教师桌面端与学生移动端实操通过，控制台无应用错误。
- 提交前确认没有暂缓课堂活动的代码、路由或数据结构残留。
